# M7 Rigid Fit

M7 fits a rigid body with two axles to a whole bus or truck segment, anchored on the tyres found in the SAM masks.
It is the slowest method, about a minute per segment on one core. `VehFootPrinter(workers=..., cache_dir=...)` runs
the segments in parallel and caches each solve.
