## [P3] Refresh the invalid-projection summary in §15

**Location:** design §15, line 824.

The deliberate-changes table still says invalid-projection rows are “never extrapolated” and “here they have no position.” That is broader than the revised §7.7 and §9: an interior `box_rejected` kinematic row can receive an admitted M7 position, and an unmeasured interior row can receive a smoothed prediction. Only the excluded `seg = -1` rows are guaranteed to retain NaN positions.

Update the summary to distinguish invalid box measurements from final position availability. Suggested replacement:

> Invalid-projection input rows are retained without box-derived measurements. Prefixes, suffixes, and unbridged missing runs receive `seg = -1` and no position. Interior rows in valid segments may receive smoothed predictions or admitted M7 kinematic measurements under §7.7.

This is an editorial correction; the detailed operational rules already specify the intended behavior.
