    TrackSmoother¶

    smoother ¶

    TrackSmoother: segment projected ground tracks, fill gaps, smooth the positions with a chosen method.

    track tables with frame, track and two position columns in metres (a ground plane the user projected

    beforehand; default names x, y), optionally interp (0 detected, 1 filled upstream), a per-row sigma column and three per-row covariance columns. Any other columns are carried through. No homography is involved.

    Outputs: the input columns first, unchanged and in their order (NaN on rows filled here), then the added columns. smooth() adds seg, fill_reason, smooth (two columns) and fallback (1 = segment too short for the method, raw positions copied); interp (0 detected, 1 filled upstream, 2 filled here) is updated in place, or added at the front when the input lacks it. compare() adds seg, fill_reason, then (two columns) and fb_ per method . Speeds are not computed here: pass the smoothed positions to tssa.speed.SpeedCalculator.

    Segmenting once, smoothing many times (design docs/2026-11-10-footprint-design.md, section 5.2): segment() returns the structural table only (track, frame, seg, seg_len, interp, fill_reason, gap_id). smooth(..., segmented=True) takes those columns from its input and does not re-segment: a row is a measurement exactly when seg >= 0 and its position is finite (interp is provenance only), observations come only from this call's positions, and seg = -1 rows come back with NaN positions.

    TrackSmoother ¶

    TrackSmoother(
    method: str = "sg7",
    params: dict | None = None,
    config: SmoothConfig | None = None,
    **config_overrides,
)

    Smooth ground-plane trajectories with a selectable method and parameters.

    method: a name from available_methods() (ma, sg5, sg7, rts, or a kind such as sg). params: overrides of that method's parameters, e.g. method="sg", params={"win": 9}. config: a SmoothConfig; keyword overrides (fps=15, xy_cols=("e", "n"), ...) are applied on top.

    Gaps are classified against ref_tracks when given (the tracks before gaps were emptied or filled upstream, in the same position columns, which tells jump gaps from plain occlusion gaps). Without it every gap that is short, implies a plausible speed and does not jump is filled ("unverified" fills).

    def segment(self, tracks: pd.DataFrame, ref_tracks: pd.DataFrame | None = None,
            allow_missing: bool = False) -> pd.DataFrame:  # fmt: skip
    """Structural table (track, frame, seg, seg_len, interp, fill_reason, gap_id): split at jumps, fill gaps.

    One row per input row (repeated (track, frame) rows dropped) plus the inserted rows (interp = 2). No
    positions are returned. With `allow_missing`, rows without a finite position are kept: an interior run inside
    a filled gap stays in that segment (fill_reason "no_position"); any other such row gets seg = -1.
    """
    df = segments.prepare(tracks, self.config, allow_missing=allow_missing)
    ref = segments.prepare(ref_tracks, self.config, allow_missing=True) if ref_tracks is not None else None
    return segments.structure(df, ref, self.config)

    def smooth(self, tracks: pd.DataFrame, ref_tracks: pd.DataFrame | None = None,
           segmented: bool = False) -> pd.DataFrame:  # fmt: skip
    """Smoothed table for the configured method (see the module docstring for `segmented`)."""
    if segmented:
        return self._smooth_segmented(tracks, [(self.method, self._kind, self._merged)], ref_tracks, single=True)
    df, grid = self._grid(tracks, ref_tracks)
    out = self._apply(grid, [(self.method, self._kind, self._merged)])
    return self._finish(out, grid, df, [self.method], single=True)

    def compare(self, tracks: pd.DataFrame, methods=None, ref_tracks: pd.DataFrame | None = None,
            segmented: bool = False) -> pd.DataFrame:  # fmt: skip
    """Every method side by side on one segmentation and gap fill.

    `methods` is a list of names or a dict name -> parameters; None means every preset (ma, sg5, sg7, rts).
    """
    if methods is None:
        methods = list(PRESETS)
    specs = list(methods.items()) if isinstance(methods, dict) else [(m, None) for m in methods]
    resolved = [(name, *resolve(name, p)) for name, p in specs]
    if segmented:
        return self._smooth_segmented(tracks, resolved, ref_tracks, single=False)
    df, grid = self._grid(tracks, ref_tracks)
    out = self._apply(grid, resolved)
    return self._finish(out, grid, df, [n for n, _, _ in resolved], single=False)
